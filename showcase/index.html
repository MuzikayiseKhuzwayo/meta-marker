Engineered for Pure Determinism

Three clean layers decouple operator presentation from gateway orchestration and mathematical execution.

Layer 1: Presentation

Cockpit & Showcase

Dark cyberpunk web interface rendering high-frequency canvas candlestick charts with interactive drag/pan history.

  • Real-time HTML5 Canvas Chart
  • SVG Dual-Arc Confidence Dial
  • Prediction Audit Ledger & CSV Export
  • Engine Bridge Diagnostics Tab
Layer 2: Gateway

Unified Control & Stream

Single-port FastAPI server consolidating REST queries, WebSocket broadcasts, and first-class CLI subcommands.

  • WebSocket /ws Real-Time Pub/Sub
  • Audit CSV & Candle JSON Exports
  • First-class CLI (serve, classify, audit)
  • Health & Memory Telemetry Endpoints
Layer 3: Execution

Deterministic Engine

Stateless indicator mathematics, closed-bar empirical scoring, and SQLite persistence with universal fallback.

  • MT5 Native DLL + Synthetic Brownian Sim
  • ADX, EMA, RSI, MACD, Stochastic, BOS
  • Closed-Bar Win-Rate Scoring Loop
  • Half-Kelly Dynamic Position Sizing
